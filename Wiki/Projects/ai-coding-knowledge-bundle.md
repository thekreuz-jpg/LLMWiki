# AI Coding Knowledge Bundle

## Status

Active

## Description

An example OKF bundle that packages up a creator's favorite AI coding YouTube videos into a shareable knowledge base. It demonstrates how OKF enables content creators to share their knowledge with the world in a format that any agent can consume.

## Goals

- Demonstrate the OKF standard in practice
- Make it easy for viewers to bring video content into their second brain
- Enable agents to answer questions about AI coding using structured knowledge
