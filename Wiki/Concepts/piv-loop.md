# PIV Loop

## Definition

The PIV loop is the primary mental model for AI coding, teaching users to Plan, Implement, and Validate whatever they are creating with a coding agent.

## Key Points

- Plan: Define what you want the agent to build before starting
- Implement: Let the agent write the code
- Validate: Verify the output meets your requirements
- This process is essential for getting reliable code from AI coding assistants
