# Open Knowledge Format

## Definition

Open Knowledge Format (OKF) is a standard for building and sharing LLM wikis, released by Google. It standardizes both folder organization and metadata fields so that agents can reliably consume and produce knowledge bases across different users.

## Key Points

- OKF is minimally opinionated — the `type` field is the only required metadata
- It enables "bundles" — packaged wikis that can be shared between agents and people
- The standard supports progressive disclosure: index files give agents a high-level overview before drilling into full documents
- OKF is positioned as the knowledge-base equivalent of MCP for tool communication
