# Context Engineering

## Definition

Context engineering is the practice of carefully selecting and structuring the information you provide to an AI coding assistant to get reliable, high-quality output.

## Key Points

- Identified as the single most important concept for getting reliable code from AI coding assistants
- Involves progressive disclosure: giving the agent just enough context to find the answer itself
- Works hand-in-hand with structured knowledge bases like OKF wikis
