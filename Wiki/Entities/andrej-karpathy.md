# Andrej Karpathy

## Type

Person

## Description

AI researcher and educator who popularized the LLM wiki concept through a GitHub gist that reached 40,000 stars. His original idea involved using AI coding agents to incrementally build and maintain a persistent wiki with structured, interlinked markdown files.
